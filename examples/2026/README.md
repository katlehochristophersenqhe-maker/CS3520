# CS3520 Examples: 2026

This folder contains examples used during the 2026 offering of CS3520.

## Examples

- `array-max`: C++ model and RISC-V assembly worked example for finding the maximum array element.
- `hello-world-assembly`: RISC-V assembly example that prints a hello world message.
- `prime-reversible-squares`: starter files for the prime reversible squares example.
